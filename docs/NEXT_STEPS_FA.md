# گام اول برای شما

این بسته، پایهٔ اجرایی پروژه است. سطح پیشرفتهٔ شما و رم ۱۶ گیگابایت یا بیشتر
در انتخاب پیش‌فرض‌های M5 لحاظ شده‌اند: ۵۰۰ سری، ۷۳۰ روز سابقه، افق ۲۸ روز،
۴ رشتهٔ پردازشی و نمونه‌گیری هفتگی مبدأهای آموزش. مصرف حافظه را پیش از افزایش
تعداد سری‌ها اندازه می‌گیریم.

۱. بسته را استخراج کنید و پوشهٔ `demandcast` را در ویرایشگر باز کنید.

۲. مطابق README یک محیط مجازی بسازید و بسته را با وابستگی‌های ML نصب کنید.
دستورهای نصب و اجرا برای ویندوز و لینوکس/مک در README آمده‌اند.

۳. آزمون‌ها و دموی مصنوعی را اجرا کنید. خروجی این دمو معیار عملکرد روی M5 نیست؛
فقط مسیر اجرای پروژه را کنترل می‌کند.

۴. فایل‌های اصلی M5 را دریافت و در `data/raw/m5/` قرار دهید. داده‌های خام و
اطلاعات دسترسی را وارد گیت نکنید.

۵. فرمان `prepare-m5` و سپس `backtest` در README را اجرا کنید.
فعلاً فرمان `--stage holdout` را اجرا نکنید؛ این بخش برای ارزیابی پس از تثبیت مدل است.

۶. برای ادامهٔ مشترک، محتوای `metrics.csv` و `run.json` مربوط به اجرای واقعی را
ارسال کنید. اگر اجرا خطا داشت، متن کامل خطا را بفرستید. اطلاعات حساب یا رمز لازم نیست.

گام بعدی ما بررسی الگوهای دادهٔ واقعی، خطا در هر افق و فروشگاه، و انتخاب نخستین
بهبود بر اساس نتایج خواهد بود. کد LightGBM در بسته وجود دارد؛ وضعیت آزمون آن
در محیط آماده‌سازی در `VALIDATION.md` ثبت شده است.

برای ساخت مخزن شخصی، پس از بررسی فایل‌ها و انتخاب نام و مجوز کد، یک مخزن خالی
در گیت‌هاب ایجاد کنید و از راهنمای اتصال همان مخزن استفاده کنید. هنوز مخزن آنلاین
یا انتشار عمومی برای این بسته ساخته نشده است.
